# CineAlign-AR: Actor-Centric Data for Robust Autoregressive Multi-Shot Video Generation

> **Chen-Yu Liu, Sanjiv Sridhar, Tuan Truong**
> Boston University | CS523 Deep Learning

## Overview

CineAlign-AR converts a full-sequence (FS) multi-shot video diffusion model
([EchoShot](https://github.com/D2I-ai/EchoShot)) into an autoregressive (AR)
generator with constant per-shot cost, and trains it on a novel **actor-centric
dataset** that spans multiple movies per identity.

**Key contributions:**
1. **Autoregressive generation** — causal masking + sliding-window inference
   reduces per-shot complexity from O(n²) to O(1).
2. **Shot-level causal masking** — bidirectional attention within a shot,
   causal attention between shots, preventing single-shot collapse.
3. **Actor-centric dataset** — cross-movie clips of the same actor provide
   diverse lighting, background, and style, improving identity robustness.

## Quick Start (BU SCC)

### 1. Environment Setup

```bash
# Clone the repo
git clone https://github.com/Sanjiv01/CineAlign-AR.git
cd CineAlign-AR

# Run the setup script (loads modules, creates venv, installs deps)
bash setup_env.sh
```

### 2. Download Model Weights

The setup script downloads Wan2.1-T2V-1.3B automatically. If you need to do
it manually:

```bash
source .venv/bin/activate
huggingface-cli download Wan-AI/Wan2.1-T2V-1.3B --local-dir models/Wan2.1-T2V-1.3B
```

### 3. Prepare Dataset

**Option A — Traditional pipeline** (single-identity clips from any video):

```bash
# Place source videos in dataset_in/
qsub scripts/process_dataset.sh
```

**Option B — Actor-centric pipeline** (cross-movie clips per actor):

```bash
# Step 1: Get actor list from movie metadata
python actor_centric_dataset/get_actor_list.py

# Step 2: Download Condensed Movies clips
python actor_centric_dataset/download_clips.py

# Step 3: Match faces across movies
python actor_centric_dataset/actor_clip_matcher.py \
    --actor_csv data/filtered_movies_with_cast.csv \
    --video_dir data/condensed_movies/ \
    --output_dir data/actor_clips/

# Step 4: Assemble multi-shot training sequences
python actor_centric_dataset/sequence_assembler.py \
    --clip_json data/actor_clips/all_actors.json \
    --output_dir data/video/ \
    --train_json data/train.json
```

### 4. Train (LoRA Fine-Tuning)

```bash
qsub scripts/train_lora.sh
# Or run directly:
torchrun --nproc_per_node=2 cinealign_ar/train_lora.py
```

**LoRA configuration:**
- Rank: 8, Alpha: 16
- Targets: q, k, v, o attention projections
- Base model: Wan2.1-T2V-1.3B

### 5. Inference (Autoregressive Generation)

```bash
qsub scripts/inference.sh
# Or run directly:
bash cinealign_ar/generate.sh
```

## Training Data Format

Each entry in `train.json`:

```json
{
  "shots": ["clip_001_shot0.mp4", "clip_001_shot1.mp4", "clip_001_shot2.mp4"],
  "cap_list": ["A woman walks through a park.", "She sits on a bench.", "Close-up of her smiling."],
  "inner_t": [8, 8, 9]
}
```

- **shots**: paths to per-shot video clips (relative to `data_root`)
- **cap_list**: one caption per shot (generated by VLM captioner)
- **inner_t**: latent frame counts per shot (sum ≈ 25 for 125 pixel frames)

## Video Specifications

| Parameter       | Value         |
|-----------------|---------------|
| Resolution      | 832 × 480     |
| Total frames    | 125           |
| Shots per sample| 2–4           |
| Frame rate      | 16 FPS        |
| Latent frames   | ~25 total     |

## Key Differences from EchoShot

| Feature                | EchoShot (FS)           | CineAlign-AR            |
|------------------------|-------------------------|-------------------------|
| Generation mode        | Full-sequence           | Autoregressive          |
| Per-shot cost          | O(n²)                   | O(1) constant           |
| Attention masking      | Bidirectional           | Shot-level causal       |
| Position encoding      | TaRoPE + TcRoPE         | Same + causal awareness |
| Dataset                | Single-video identity   | Cross-movie actor clips |
| Inference method       | Single forward pass     | Sliding-window          |

## Evaluation Metrics

- **FaceSim-Arc**: ArcFace cosine similarity across shots
- **FaceSim-Cur**: CurricularFace cosine similarity across shots
- **Motion Score**: Optical flow magnitude for temporal dynamics
- **Background Consistency**: Gemini API visual assessment
- **Lighting Consistency**: Gemini API visual assessment
